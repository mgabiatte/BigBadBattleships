# ⚓ BigBadBattleships

---

## 🎮 Como Jogar

1.  **Fase de Posicionamento:** O capitão (player) deve digitar a Linha (0 a 4) e a Coluna (0 a 9) para posicionar os seus 5 navios. O computador irá posicionar de forma aleatória.
2.  **Fase de Ataque:** Na sua rodada, introduza as coordenadas para bombardear o território inimigo.
    * `~` representa água não revelada.
    * `N` representa seus navios.
    * `X` representa um alvo atingido.
    * `O` representa um tiro na água.
3.  **Vitória:** Vence quem conseguir afundar primeiro as 5 embarcações da frota adversária!
